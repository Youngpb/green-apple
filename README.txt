для запуска сайта нужно скачать библиотеки из файла "requirements.txt" для этого через командную строку прописываете cd "путь где лежит проект"
после чего пишете pip install -r requirements.txt
после скачивание библиотеки пишете uvicorn main:app --reload
готово,сервер работает,открываете в браузере ссылку http://127.0.0.1:8000/ и сайт работает
